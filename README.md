# 🏠 DormEase – Hostel Management System

DormEase is a C++-based hostel administration system designed to simplify and organise hostel management. It helps administrators manage student records, room allocation, attendance, complaints, leave requests and waiting lists through a structured application.

## 📌 Project Overview

Managing hostel operations manually can be time-consuming and may lead to errors in student records, room allocation and administrative activities.

DormEase aims to make these processes easier by providing an integrated system using Object-Oriented Programming and Data Structures in C++.

## 🎯 Problem Statement

Traditional hostel management involves maintaining student details, room assignments, attendance and complaints manually. This can result in duplication of records, inefficient room allocation and difficulty tracking student requests.

DormEase provides a computerised approach to managing these activities efficiently.

## ✨ Key Features

- Student registration and record management
- Room allocation and management
- Waiting list management
- Student attendance tracking
- Complaint management
- Leave request management
- Student record deletion and undo functionality
- Admin login and dashboard
- Student portal

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming
- **Data Structures:** Arrays, Stack, Queue and Linked List
- **Development Environment:** C++ compatible compiler

## 📚 OOP Concepts

The project uses Object-Oriented Programming concepts to organise its functionality.

- **Classes and Objects:** Used to represent and manage application entities.
- **Encapsulation:** Used to organise data and related operations within classes. Some data members are currently public.
- **Modularity:** Different functionalities are organised into separate source files.

## ▶️ How to Compile and Run

A C++ compiler such as GCC is required.

After confirming that the integrated source file is self-contained, compile it using:

```bash
g++ -std=c++17 Dormease.cpp -o DormEase
```

Run on Linux:

```bash
./DormEase
```

Run on Windows:

```bash
DormEase.exe
```
